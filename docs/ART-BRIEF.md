# 美術素材清單（交畀另一個 AI 出圖）

## 全域風格（每張圖都要加）
- 可愛 Q 版貼紙風，粗深棕色外框，金色 / 粉紅 / 紫色為主，皇家海雙布偶貓馬戲團主題（貓耳、貓爪、皇冠、星星）
- 同現有素材（ragdoll-atlas-1/2/3、lobby-assets-atlas）完全同一風格、同一線條粗細
- **純白背景（#FFFFFF）**；每個物件外框必須封閉，白色光暈唔可以碰到格仔邊（程式用「由邊緣向內填充」去白，外框唔封閉會穿洞）
- 圖集：2048×2048、4×4、每格 512×512、物件置中並留 ≥40px 邊距、JPEG 即可
- 唔要文字（文字由程式畫），除非特別註明
